# Fashion Milano (Men Clothes Shop)

Vite + React + TypeScript + Tailwind clone of the [Milano Shopify demo](https://demo-milano.myshopify.com/).

## Scripts

- `npm run dev` — start local server
- `npm run build` — production build
- `npm run preview` — preview production build

## Pages

- `/` — Home
- `/collections/shirts` — Shirts collection with filters
- `/products/:handle` — Product detail
- `/about` — About
- `/contact` — Contact

Cart is local-only (localStorage). Images are loaded from the Milano demo CDN.
